apeCAD github

A three-dimensional napkin.

Lines, boxes, and labels — so nobody has to describe a building in paragraphs. The Python document is the language. The window is a client.

IsSpatial scratchpad for humans and agents. apeGmsh, apeSteel, and Studio consume the draft.

from apeCAD import Document

cad = Document()
a = cad.add_point(0, 0, 0, label="A")
b = cad.add_point(6000, 0, 0, label="B")
cad.add_line(a.entity_id, b.entity_id, label="beam_B1")
print(cad.to_json())
